# MovieApp

Aplicación del taller React + TypeScript + Vite para buscar películas con OMDb.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Configuración

1. Copia `.env.example` a `.env`.
2. Completa `VITE_OMDB_API_KEY` con tu key de OMDb.

```bash
VITE_OMDB_API_KEY=tu_api_key_aqui
```

> La documentación completa del taller (estructura y niveles 0-10) está en el README del repositorio raíz.
